# kash-releases

Kash is a local-first personal budgeting app for macOS. It tracks spending,
categorizes transactions, and flags unusual charges — with all data stored in a
single database on the user's own computer, never on a server.

Bank transactions are synced through Plaid for the owner's own accounts only,
read-only (Transactions product). Bank credentials are entered in Plaid's window
and never seen by the app. Access tokens are encrypted on the device.

This repository hosts the macOS app releases. Download the latest `.dmg` from
[Releases](../../releases/latest).
